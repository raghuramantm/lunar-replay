# Can a machine tell when its own body is failing?

A side-by-side replay from my MSc dissertation on self-detection of actuator faults in
reinforcement learning policies. The same trained PPO agent lands the same site twice: once
with a healthy engine, once with the engine weakened to a quarter of its power part-way
through the descent.

Made for the poster presentation component of the dissertation, University of Aberdeen, 2026.
Supervisor: Dr Andrew Starkey.

Full study and code: https://github.com/raghuramantm/can-an-agent-tell-it-is-broken
